# HouseArt — instruções para o Claude Code

- Leia `README.md` inteiro antes de começar. Siga a sequência de fases da seção 6.
- `designs/` contém protótipos HTML de referência (alta fidelidade). Recrie no stack do projeto; não copie o HTML nem o `support.js`.
- Nenhum valor visual solto: use apenas tokens de `designs/houseart/ha-tokens.css`.
- Antes de implementar uma tela, abra o `.dc.html` correspondente e leia a lógica no `<script type="text/x-dc">` para estados, validações e textos.
- Textos em português do Brasil, exatamente como nos protótipos. Dados são exemplos.
- Não implementar gov.br. Autenticação = e-mail + celular com código, login social, biometria.
- Marca: siga a tabela de aplicação (README 4.5). Cores de submarca só nas marcas de linguagem.
- Telas listadas na Fase 8 não têm design: pare e peça design em vez de inventar.
